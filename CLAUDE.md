This project provides a Telegram bot that can notify users when their
IV scheduling changed.

User can register their country and Visa Category, including
Immediate Relative, Family-Sponsored Preference, and Employment-Based Preference.
Then receive notice when government source update.

You can find current IV scheduling status data at github project:
 https://github.com/jyunfan/IVSchedulingStatusTracker

Deploy to machine "iv" using ssh
